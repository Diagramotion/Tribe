# Tribe v0.2.0

This release moves the standard desktop app to Electron on Apple Silicon macOS and 64-bit Windows. The installers include Tribe’s managed Chromium browser and local Python runtime. The earlier v0.1.0 Tauri release remains available in its original assets.

## Highlights

- Configure remote HTTP and local stdio MCP servers once for the workspace, with project-level exclusions and role-granted tools.
- Use the managed browser in the desktop app for live pages, inspection and agent-driven browser work.
- Improve design-system authoring and previews, project workspace navigation, repository views and artifact handling.
- Keep Tauri commands available as a legacy development path; tagged releases publish Electron installers.

## Downloads

- Apple Silicon macOS: `Tribe-v0.2.0-macos-arm64.zip`
- 64-bit Windows: `Tribe-v0.2.0-windows-x64-setup.exe`
- `SHA256SUMS` contains checksums for the release files.

macOS releases are signed and notarised. Windows installers are unsigned and may show a SmartScreen trust prompt.
