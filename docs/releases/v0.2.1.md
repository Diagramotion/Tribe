# Tribe v0.2.1

This patch release fixes Electron release version stamping when the package version already matches the release tag.

The release uses the Electron desktop app with the managed Chromium browser. It includes the workspace MCP configuration and usability improvements from v0.2.0.

## Downloads

- Apple Silicon macOS: `Tribe-v0.2.1-macos-arm64.zip`
- 64-bit Windows: `Tribe-v0.2.1-windows-x64-setup.exe`
- `SHA256SUMS` contains checksums for the release files.

macOS releases are signed and notarised. Windows installers are unsigned and may show a SmartScreen trust prompt.
