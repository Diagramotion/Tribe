Tribe v0.1.0 is the first public desktop release of the local-first AI team workspace for software engineering.

## Included

- Apple Silicon macOS application bundle (`.app` in a ZIP archive).
- 64-bit Windows installers (MSI and NSIS).
- SHA-256 checksums for the installers.

This release ships the Tauri desktop application and its local Python runtime. The managed Chromium browser in the separate Electron shell is not included.

## Before installing

These installers are not code-signed or notarised. macOS may require you to Control-click the app and choose **Open** the first time. Windows may show a SmartScreen warning. Verify the downloaded file against `SHA256SUMS` before opening it.

Tribe does not include model access or provider credentials. Configure a hosted provider or a local model endpoint in Settings. Hosted model requests send the prompt and relevant project context to that provider under its terms.
