# Tribe v0.2.1 alpha 1

This early test release ships the Electron desktop app with the managed Chromium browser and workspace MCP configuration.

Please report any problems you find. This build is unsigned while Apple Developer signing is being set up.

## Downloads

- Apple Silicon macOS: `Tribe-v0.2.1-alpha.1-macos-arm64.zip`
- 64-bit Windows: `Tribe-v0.2.1-alpha.1-windows-x64-setup.exe`
- `SHA256SUMS` contains checksums for the release files.

### Open on macOS

After extracting the app, run this in Terminal from the directory containing `Tribe.app`, then open the app:

```sh
xattr -cr Tribe.app
```

Windows installers are unsigned and may show a SmartScreen trust prompt.
