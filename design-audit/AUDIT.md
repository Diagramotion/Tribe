## Known visual fix

Long lines in Markdown and plain-text Git diffs were clipped. The current view wraps prose diffs while keeping source-code diff lines horizontally scrollable. This was visually checked in the live pane.

Expanded test output also overflowed its workspace pane on long stack-trace paths. Constraining the output block and allowing long tokens to wrap removed the pane-level horizontal scrollbar; expanded output was rechecked live at 1536×855.

The Tests result row let expanded output consume the metadata column because the output was styled for a grid but the row used flex. The row now uses a two-column grid; the failed test name and status remain readable above the contained output, and the Running result stays visible below it.

Initial Tests loading displayed both the `repo.test_run.started` and `repo.test_run.completed` events as separate runs, leaving a false Running row beside the actual failure. Initial loading now merges the lifecycle by run ID, matching live updates. After a full reload the fixture shows one Failed result, not duplicate Failed and Running rows.

Selecting a chat from another project could call the resume path with the current project's mission list, activating the other chat without changing the project. Sidebar selection now passes the owning project; the workspace switches to that project and resolves the chat from its mission list before any resume fallback. A paused chat was selected live and stayed paused.

The workflow editor sanitised punctuation into a hyphen-only ID and enabled Create once other fields were complete, while the runtime rejects IDs that do not start with a lowercase letter or digit and contain 2–64 valid characters. The editor now shows the matching ID rule inline and disables Create until it passes. The invalid state was checked live and cancelled without saving.

The saved split-pane width could use 82% of the workspace and leave chat at 320px. This contradicted the current 60% pane cap, 820px pane maximum and 360px chat minimum. The persisted value is now clamped through the same sizing helper used by drag and keyboard resizing; the chat grid enforces its minimum. A pending approval plus expanded test output at 1280×720 confirms both panes remain readable.

The unread-message pill overlaid older message content when the reader was scrolled up. It now occupies a separate row between the timeline and approval/composer, preserving the reader's position while keeping message text unobscured.

The Workflows no-selection detail state repeated the New workflow action already available in the page header. Its redundant CTA is removed so the plus icon is the only create action; the detail state now gives concise guidance instead.

Project Artifacts showed a file/result count beside a separate shared-documents list without naming what the count covered. The count now reads “Files & results” and was visually rechecked with both content types present.

Project Knowledge used full-text Archive and Restore utility actions in each note row. These are now compact icon buttons with title-specific accessible names; active, archived and restored states were exercised in the disposable UX Review Lab fixture.

Project creation previously enabled Add project for any non-empty clone address. It now validates supported HTTPS and SSH forms in the client, describes the accepted formats beside the field, and blocks invalid input before submission.

At narrow overlay widths, the active workspace tab could remain outside the clipped tab strip after opening it. The tab strip now scrolls the selected tab into view when the selection or open set changes; this was checked live at 768px.

At a 768px browser width, the “Needs you” popover exceeded the available space to the left of its right-aligned trigger; it now anchors from the left at tablet widths and uses a viewport-bounded fixed placement on phone widths. The Plan pane's header is now stacked at compact workspace container widths so the goal text cannot be squeezed by the action group.
